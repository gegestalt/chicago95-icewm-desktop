# Changelog

## v1.0.0

First tagged release. Everything below is already in `master`.

### Desktop
- Start menu with every installed app, auto-generated by category
  (`icewm-menu-fdo`), plus curated quick-launch shortcuts.
- Taskbar "Applications" button — a flat, one-page, alphabetized grid of
  every installed app (`~/Applications`), kept in sync on every login.
  Icon is a from-scratch 3x3 grid glyph matching Ubuntu's app-grid icon.
- HiDPI-correct IceWM window chrome: the stock theme's pixel-art title-bar
  buttons and borders are sized for ~96 DPI and render tiny on a HiDPI
  screen unless upscaled to match. Ships both a 1x and a 2x asset set;
  `install.sh` measures the real display DPI and picks the right one.
- Theme-consistent default apps (`gpicview`/`evince`/`mpv`/`pcmanfm`,
  `xfce4-settings-manager`) in place of GNOME's GTK4 apps, which cannot be
  reskinned by any classic GTK theme.
- GSettings synced to the theme so GTK4/portal-aware apps stop falling
  back to Yaru/Adwaita.
- LightDM greeter configured for Chicago95 with the correct DPI.

### Installer
- `install.sh` — idempotent, DPI-aware, and self-backing-up: every file it
  overwrites is backed up first, every GSettings key it changes has its
  old value recorded, under `~/.chicago95-icewm-desktop/backups/<run>/`.
- `uninstall.sh` — reverts a previous `install.sh` run from that backup.
- `optional/migrate-firefox-to-deb.sh` — replaces a snap-installed Firefox
  (sandboxed away from any custom theme) with Mozilla's official `.deb`,
  migrating the existing profile across. Opt-in, not run automatically.

### CI
- `.github/workflows/lint.yml` — `bash -n` and ShellCheck on every push
  and PR.

### Games
- ClackType — a from-scratch typing-speed test (not the real Monkeytype):
  word-by-word correct/incorrect/extra highlighting, live WPM/accuracy,
  time and word-count modes, and a results-screen graph (WPM/raw over
  time, with error ticks) built as an inline SVG. Single self-contained
  HTML file, no build step, no network dependency.

### Known limitations
- GNOME Settings, Nautilus, and other libadwaita apps cannot be reskinned
  — a GTK4 design decision, not something a theme can work around.
  `install.sh` replaces them with themable equivalents instead.
- `install.sh` has been tested against a sandboxed `$HOME` (verified the
  backup/restore round-trip and caught real bugs that way) but not yet
  end-to-end on a genuinely fresh Ubuntu install.
